# LIGHT

Lighting that plays like Resolume. LIGHT sits between Resolume Arena and your
lighting rig. You build looks in a clip grid and fire them from columns, MIDI
pads or Resolume itself. Effects follow the beat, there is a 3D stage view, and
Art-Net or sACN goes out at a steady 40 Hz.

This repository is where LIGHT's releases and user guides are published. The
source is private.

## Download

**[Latest release](../../releases/latest)**: download `LIGHT-<version>.dmg`,
open it and drag LIGHT to Applications. It is for Apple Silicon Macs, signed
with a Developer ID and notarised by Apple, so it opens with a double-click.
It does not run on an Intel Mac. On first launch, allow local network access:
Art-Net and sACN need it to reach your rig.

LIGHT starts a free trial the first time it opens. Licences are sold at
[letissier.ie](https://letissier.ie). Once installed, LIGHT checks this
repository for newer builds and tells you when one is out. It never installs
anything without asking.

## Feedback and problems

In LIGHT, go to **Setup ▸ Help ▸ Send feedback…**. It reaches the studio
directly and waits in a queue if you are offline. Licence questions go through
[letissier.ie](https://letissier.ie).
